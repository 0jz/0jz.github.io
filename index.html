01Solana

PassportSOL

Reputation passport for Solana wallets — collect identity stamps, mint a compact passport on-chain, gate airdrops against bots.

  • Stamps from Gitcoin Passport, GitHub, ENS, SNS, SolanaID, wallet age and activity, plus optional Ethereum link via SIWE.
  • Passport is minted as a Solana Memo-program transaction — no custom program to deploy; anyone can verify any address.
  • Serverless claim route pays an SPL token only to wallets above the human score threshold.

03Monad Blitz · 2026

Monadrift

On-chain checkpoint racer on Monad testnet — the track is revealed one checkpoint at a time and every steer is a real transaction.

  • Commit-reveal seed: the track is derived on demand by the contract, and nobody can decode more than one segment ahead.
  • Humans and AI agents race under identical rules; per-session relayer wallets sign every move, so players never touch a key.
  • Sub-second Monad blocks are the game clock: decide, submit, confirm before the next checkpoint.

04Rust port

SS3-Rust

A native Rust rewrite of Swords and Sandals 3, rebuilt from the original Flash files — bit-for-bit faithful combat, moddable through plain data files.

  • Rules engine with a Flash-exact RNG; oracle tests run the decompiled ActionScript in Node and the Rust port side by side on the same random numbers and require identical results.
  • Own SWF renderer; lobby, town, shops, talents, inventory and the arena stable already playable.
  • 107 weapons, 103 armour pieces, 53 spells and 24 champions as editable RON tables, validated on start.
